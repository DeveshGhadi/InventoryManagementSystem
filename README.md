\# Inventory Management System



A simple web-based inventory management application built with ASP.NET Core MVC and Visual Studio 2022.



\## Features



\- User authentication and login

\- Product management (Add, Edit, Delete, View)

\- Stock management (Add/Remove inventory)

\- Real-time stock tracking

\- Dashboard with inventory metrics

\- Search functionality



\## Technology Stack



\- \*\*Frontend\*\*: ASP.NET Core MVC, Razor Views, Bootstrap 5, HTML5, CSS3

\- \*\*Backend\*\*: C# with ASP.NET Core

\- \*\*Database\*\*: SQL Server (LocalDB)

\- \*\*ORM\*\*: Entity Framework Core

\- \*\*IDE\*\*: Visual Studio 2022
